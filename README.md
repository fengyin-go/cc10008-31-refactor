# 交互式数据分析工作台

离线版交互式数据分析工具，涵盖多源接入、查询分析、可视化图表、报告生成、异常检测与数据服务编排，所有分析配置与结果持久化到浏览器本地存储。

这是一个**纯前端**管理平台：React + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 React + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `interactive-analytics-lab:entries` 这一项，或调用 `resetModule(模块)`。

## 数据分片领域（segment）

数据分片不使用通用的单表动作链，而是在 `frontend/src/data/segment/` 下独立建模，把三条生命周期拆开：

- `types.ts`：规则 `SegmentRule`、分片结果 `ShardResult`、迁移批次 `MigrationBatch` 三类独立实体。
  结果与批次只按 `ruleId`（编号）引用规则，并内嵌「生成时配置快照」，改草稿、改名称都不会回改历史。
- `policy.ts`：纯判定与纯计算。规则命令链与迁移命令链共用同一套 `assertX` 守卫（启用判断、名称查重、
  状态机、迁移中保护），稳定哈希分片与倾斜判定也在这里，不依赖存储与 React。
- `store.ts`：持久化与命令入口。所有写操作走 `commit()`：先在克隆状态上完成全部校验，再一次性落盘；
  落盘抛错时整体回滚到提交前，规则与迁移计划不会出现半成状态。独立 localStorage 键
  `interactive-analytics-lab:segment`。
- `seed.ts`：用 `policy.ts` 的纯函数生成种子，保证示例数据本身就满足全部不变量。

关键不变量（`segment.test.ts` 逐条覆盖，共 14 个用例）：

1. 启用判断与迁移计划拆分，草稿修改不污染现有计划与分片结果；
2. 保存失败时规则与计划整体回到旧状态；
3. 停用后历史任务/批次可查，新迁移计划一律拒绝；
4. 计划生成不暴露半成品（全部校验通过才一次性提交）；
5. 恢复启用按当前倾斜阈值重新校验，下一次评估按新阈值重判；
6. 历史结果与批次保留生成时的分片数量、迁移策略、触发条件；
7. 分片算法切换不回改已生成候选的归属，迁移中候选跨评估原样携带；
8. 再平衡触发条件变化只影响下一次计算；
9. 只能删除草稿规则，且不级联删除已引用的历史批次与结果；
10. 迁移中的候选不能被重新判定为已平衡；
11. 迁移失败的节点回到原分片、状态退回倾斜，迁移原因与失败原因都留证；
12. 规则名称重复阻止保存，历史结果只按编号引用。
